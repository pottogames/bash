# plan2quote

מתוכנית אדריכלית → כתב כמויות → הצעת מחיר → חבילות עבודה לכל גורם.

**בלי AI.** כל מספר במערכת הוא סכימה של קואורדינטות מהקובץ, וכל סיווג שכבה הוא
כלל שכתוב במפורש בקוד וניתן לקריאה ולתיקון. אין מודל בשום מקום במסלול.

> הריפו הזה החזיק קודם סקריפט bash לימודי. הוא נשאר ב-`legacy/main.sh`.

---

## למה בלי מודל, ולא רק בגלל העלות

מודל שמחזיר ‎97 מ״ר לא יכול להראות לך את הקווים שהוא סכם, ולא מתחייב לתת את אותו
מספר מחר. שני הדברים האלה הם התנאי לכך שקבלן יסמוך על כמות שהוא לא ספר בעצמו.

מה שיש כאן במקום:

- **מדידה** — אריתמטיקה מדויקת על הקואורדינטות. נוסחת Shoelace עם הזזה לנקודת
  ההתחלה, קשתות בצורה סגורה (לא טסלציה), קינון זוגי-אי-זוגי לחורים ואיים, זיהוי
  ישויות כפולות, וסכימת Kahan.
- **סיווג** — מילון מונחים בעברית ובאנגלית, תקני שמות שכבות (AIA / ISO 13567),
  וראיות מתוכן השכבה. כל סיווג מגיע עם רשימת המשפטים שגרמו לו.
- **למידה** — כשמישהו מתקן שיוך, התיקון נשמר ככלל ארגוני ונבדק ראשון בייבוא
  הבא. המערכת מכירה את מוסכמות השמות של המשרדים שאתה עובד איתם, בעלות אפס.

## הרצה

```bash
git clone -b claude/construction-plans-system-40nm0n https://github.com/pottogames/bash.git
cd bash
corepack enable                    # מפעיל pnpm בגרסה שהפרויקט מצפה לה
pnpm install
pnpm build                         # tsc -b על כל החבילות
pnpm --filter @plan2quote/web dev  # http://localhost:3000
```

בדיקות:

```bash
pnpm test               # 189 בדיקות יחידה
./scripts/test-db.sh    # מיגרציות + 15 תרחישי RLS מול Postgres
```

### אירוח ציבורי

`.github/workflows/pages.yml` בונה ייצוא סטטי ומפרסם אותו ל-GitHub Pages.
הוא לא ירוץ עד שמישהו עם הרשאות אדמין יגדיר פעם אחת
**Settings → Pages → Source → GitHub Actions** — ה-token של ה-Actions לא מורשה
להפעיל את Pages בעצמו. אחרי ההגדרה מריצים את ה-workflow ידנית (Actions →
Deploy demo to GitHub Pages → Run workflow), והאתר יעלה על
`https://pottogames.github.io/bash/`.

`scripts/test-db.sh` מצפה ל-Postgres זמין (ראה משתני `PG*`). הוא לא דורש את
Supabase CLI — `supabase/tests/00_auth_stub.sql` מספק את `auth.users` ואת
`auth.uid()`, שזה כל מה שהסכימה צריכה משם.

## אבטחה

הכל נאכף במסד הנתונים, לא בממשק. מודל האיום הוא לא באג ב-UI אלא קבלן משנה
שמעתיק את ה-JWT שהאפליקציה כבר נתנה לו ופונה ישירות ל-PostgREST.

- **אין הרשמה פתוחה.** חשבון נוצר רק מול קוד הזמנה שאדמין הנפיק. הקוד עצמו לא
  נשמר — רק גיבוב SHA-256 ורמז בן ארבעה תווים — והוא קשור לכתובת מייל אחת.
- **הרשמה ≠ הרשאה.** מימוש קוד יוצר חברות בסטטוס `pending_approval` שלא רואה
  כלום. אדמין חייב לאשר את התפקיד וההרשאות במפורש, ולציין מחדש את התפקיד שהוא
  מאשר. אין שום מדיניות שמאפשרת ללקוח לכתוב `active` — גם לא לבעלים.
- **עלויות בטבלה נפרדת.** `quote_line_costs` היא טבלה משלה עם מדיניות משלה.
  טעות במדיניות יכולה לדלוף שורות שגויות, אבל לא עמודות שגויות.
- **גישה עם תפוגה.** לכל נמען חבילה יש `access_expires_at`. אחרי סגירת המכרז
  הכניסה נסגרת בלי שאף אחד צריך לזכור.

הבדיקות ב-`supabase/tests/10_rls.test.sql` תפסו שני באגים אמיתיים בזמן הפיתוח:
`has_project_permission` הוגדרה לפני שהטבלה שהיא קוראת קיימת, וכל מדיניות כתיבה
שנכתבה כ-`for all` הרחיבה גם קריאה — מה שאיפשר למי שיש לו `price.update` לקרוא
מחירי עלות אחרי ש-`price.cost.read` נשללה ממנו במפורש.

## למה גיליון פרטים לא נמדד

זו הטעות הכי יקרה שהמערכת יכולה לעשות, והיא לא נראית כמו טעות.

גיליון פרטים — שישה פרטי איטום ב-1:5 וב-1:10, כל אחד עם הצללת בטון משלו — נראה למנוע
מדידה בדיוק כמו תוכנית קומה מלאה בחדרים. נמדד בקנה המידה הנומינלי של הגיליון הוא מייצר
כמה מאות מטרים רבועים בטוחים לחלוטין שלא מתאימים לשום דבר, ושום דבר בתוצאה לא נראה חשוד.

לכן לפני שמודדים משהו, הגיליון חייב להצהיר מה הוא. הסימנים כולם טקסטואליים וקיימים בכל
שרטוט ישראלי אמיתי: תוויות `פרט מס׳ N` חוזרות, שני קני מידה שונים או יותר על אותו גיליון,
או `חתך` ו-`חזית`. גיליון כזה מיובא, מוצג, ולא נכנס לכתב הכמויות — עד שמישהו מסמן אותו
ידנית. הסירוב נאכף בשלושה מקומות: בממשק, ב-worker, ובטריגר במסד הנתונים.

## מה עדיין צריך ממך

1. **קובץ תוכנית אמיתי אחד** — DXF או PDF, אפשר אנונימי. הפרסר נבדק מול קבצים
   שנבנו ביד; קובץ אמיתי אחד יגלה יותר מעשרה סינתטיים.
2. **רשימת המקצועות שאתה עובד איתם בפועל**, בשמות שאתה משתמש בהם. הטקסונומיה
   הנוכחית היא 22 מקצועות סטנדרטיים, והמילון מכוון אליהם.
3. **פרויקט Supabase** — המיגרציות מוכנות להרצה.
